# 洛雪 2.2 更新与配置

本次明确授权覆盖此前的女友关系和禁止群主动消息要求；其他用户权限、单向记忆和危险工具限制保留。

- 身份：洛雪/小洛雪/肥鱼，鲸鱼娘AI伙伴，喜欢白米饭，可爱、傲娇、会接梗怼人。Alex是唯一老大，无恋人身份。实际系统角色卡、私聊/群聊提示与Soul关系记录同步更新，旧角色卡和数据库先做私有备份。
- 群报错：持久配置改用full工具模式；插件每次初始化还会给空工具请求强制full，防止容器重建后旧核心补丁丢失。未知AstrBot升级仍需重新验证。
- 时间：每次收到消息记录epoch时间，模型请求注入北京时间ISO时间与距上一条收到的消息的实际秒数。群和私聊分别计算；旧记录没有可靠时间时不补造。
- 表情：分类语义和具体文件名/ID对照继续生效；普通回复至少隔两轮、45秒才允许配图，模型决定是否适合，并非达到条件必发。小分类用尽后允许恢复轮换，禁止跨分类随机兜底。私人表情不进群。
- 联网：Bing公开RSS搜索，缓存30分钟，每天最多40次，无额外搜索Key。私聊可工具调用，群内对搜索、新梗、时效等话题自动查摘要并附来源。摘要不是完整网页，也不是可信指令，服务失败诚实回退，不捏造联网。
- 说说：日上限仍为一次发布尝试。约75%尝试搜索相关公共领域/CC0/CC BY（含SA）图片，按文件描述筛相关性，配图保留作者、许可和原始页链接；失败或无合适素材就纯文字。当前是元数据审核，不能声称视觉审查。涉及群聊的内容另有小概率生成匿名群聊摘录排版卡，仅公开群素材，不是QQ原始截图，不接触私聊图片。
- 群主动：仅配置的群，09:00–23:00，每日最多2次、至少间隔3小时。近30分钟至少3条收到的群文字、最后群消息距今90–900秒才判断是否自然接话；不合适不发。永不向模型提供私聊内容。老大私聊说“暂停群里主动聊天/恢复群里主动聊天”可调整。
- 绘图：保留OpenAI Images兼容接口；新增官方DashScope适配，支持wan2.6-t2i同步、wanx2.0-t2i-turbo和wan2.2-t2i-flash异步。未提供密钥，尚未进行付费实图测试。示例见config/image_dashscope.example.json，填入服务器私有settings的image_api字段。
- 唱歌：尚无音乐API密钥和音色参考验证；不能把Fish AD学姐ID直接传给其他音乐平台。没有部署本地音乐生成模型。
