# 内置联网搜索

联网查询由 `luoxue_social.web_search` 直接调用 Tavily Search 或 Brave Search API，不通过第三方搜索插件，也不使用匿名 RSS 兜底。

在控制台「联网搜索」页解锁后选择服务、填写密钥并保存。留空保留该服务的密钥，切换服务会使用分别保存的密钥。配置写入插件数据目录中的 `search-config.json`，不进入模型上下文或机器人状态，也不随源码发布。接口只回传是否已配置，不回传密钥。保存后无需重启。

Tavily 固定使用 Basic，关闭自动调参和额外答案生成，每个调用按一个 credit 预留预算。默认每天最多 25 次、每月最多 900 次，按中国标准时间重置。失败请求也预留一次预算，因此本地计数可能高于服务商实际扣费；缓存命中不重复预留。此限制只统计当前实例，不能约束共用密钥的其他应用，应同时检查服务商余额和计费设置。

并发相同查询通过锁和缓存合并。普通结果缓存 30 分钟，时效结果 5 分钟，失败结果 30 秒。查询在发送前检查隐私字段，洛雪的决策模型读取当前会话中经过隐私清洗的近期对话，搜索服务只收到她选定的公开查询词，不收到聊天记录。结果保留相关网页摘要和来源链接，排除明显无关、重复或无效 URL。关键词过滤不能保证来源真实或语义完全相关，摘要仍作为不可信资料处理。未配置、超限、超时和无相关来源都明确返回失败，提示模型不编造搜索过程和词义。

受密码保护的接口为 `GET /roomapi/search/status` 和 `POST /roomapi/search/config`。密钥仅经 POST 提交，配置文件通过私有临时文件原子替换。模型没有配置修改工具。

离线测试覆盖缓存去重、预算限制、两家 API 请求、无密钥拒绝、相关性过滤、密钥不回显和配置保留。真实服务可用性必须另外用有效密钥验证，浏览器表单测试不能代替实际搜索。

是否搜索及查询内容由洛雪使用当前聊天模型自主决定，没有关键词触发器或随机抽签。决策包含当前消息、同一会话最近的有限对话、她此刻的公开状态，以及每日和每月上限、已用和剩余次数。公开群决策不读私聊，私聊决策不混入公开群消息。模型可选择搜索、直接回应或先问清主题。关键词、搜索命令和问号都不直接决定是否执行。

没有配置密钥、额度耗尽或决策失败时不执行外部搜索，也不会退回关键词触发。真正发起搜索时仍由并发锁和硬预算限制兜底。决策记录保存在私有状态的 web_decision_log 中，标明 source=model，可区分她决定没搜、无法决定和实际检索失败。

自主决策也可选择 read，直接读取一个公开 HTTPS 页面，或通过 GitHub 公开 API 读取仓库的 archived、disabled、更新时间和 README。读取有独立每日上限，默认 20 次，每次仓库读取最多两个 HTTP 请求。传输沿用 SSRF 防护，不提供身份凭据，不支持私人仓库；抓取失败、受限或 404 都不直接推断仓库已删除。模型看到当前真实日期、检索时间和单独的发表日期字段，缺失日期保持未知。

独处自学默认每三小时至多获得一次机会，由模型决定是否搜索、读原页或这轮不查。只向决策提供公开状态，不读取私人对话；只有真实成功的资料访问才记为完成，摘要与原页分别标明。它与聊天共用搜索和网页预算，可通过 public_learning_enabled 关闭，也受自主活动总开关控制。

第一次读取或搜索失败时，可由模型再选择换查询、读已知原页或停止。本轮最多补充一次操作，不强制重试，不回退关键词触发；两次都没有来源就不拼凑结论。
