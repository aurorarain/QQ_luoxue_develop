# 洛雪的大脑与独处活动

## 运行边界

`luoxue_social` 持有状态并原子保存。独立的旧大脑插件曾直接覆盖同一状态文件，迁移时应停用。房间接口读取快照，通过现有控制台队列接收已认证的修改。网页和插件共用现有状态格式，旧记忆继续留在库中。

私聊上下文含关系、情绪、阅读进度和相关旧记忆。只有来源可验证的主人私聊进入自动蒸馏，公开群记录仍可在主人侧检索。群聊使用公开历史及简洁的当前状态。群内主动接话独立运行，只以配置群的公开内容为输入。

## 独处循环

每轮先取身体状态、时间、最近执行结果和当前计划，再让模型从本轮实际可用的选项中选一个。可静观、休息、续读书架、浏览已配置的贴吧、低频私聊主人。阅读按真实页数推进，续读计划跨重启保存。启动时会把书架目录中有效且未登记的书重新入库，已登记的读书进度原样保留。休息会改变房间当前活动。没进度、接口失败和被护栏跳过分别记状态。

心跳保存选择和执行结果。模型输出只是计划，不能自行确认承诺完成，也不能在私有上下文里决策公开发送。旧承诺仍可查看，定时提醒沿用原路径。休息期间或睡觉时会减少模型调用。发给主人的主动消息有安静时段、固定目标、冷却、近期未回复检查和文本去重。QQ 平台返回成功表示接口返回，客户端收件情况需要另行确认。

主人可在 QQ 私聊发送「暂停独处活动」或「恢复独处活动」。现有的「暂停主动聊天」与「恢复主动聊天」只控制主动私聊。需要明确转发原文时，可以用「群里说：原文」。

## 脑图

七区显示现有数据。记忆强弱按重要度与保真度展示，关联线解释数据匹配或计划与能力的关系。技能区的次数来自近 60 条心跳记录，手动工具调用不计入。关系区权重是公开记录频次。页面保留原路由，部署时将 `brain.html` 同时安装为 `memories.html`。

`deploy/room_api.py`、`deploy/logs_api.py` 和 `deploy/room/` 是部署源文件。旧网页交接文档改为公开简版。脑图、详细日志、资产、控制台和修改接口在服务端验证口令。实时日志通过请求头传递口令。口令与维护者身份配置放在服务端私有配置中。

## 验证方式

运行 `python -m unittest discover -s tests -q`。部署后检查未认证读取拒绝、已认证脑图、桌面及移动浏览器搜索与节点详情、服务状态及独处日志。独立用例覆盖跨轮续读、睡着时跳过模型、禁止私有心跳选择群发、未送出不记成功、主人地址和免打扰限制。

通用部署可通过 `LUOXUE_HOME` 指定 sidecar 数据根目录，通过 `LUOXUE_API` 指定媒体中继。天气坐标和可选音色标识从环境配置读取。

## 记忆星海与洛雪的家

脑图在 Canvas 中以带景深的空间坐标投影七个脑区，旋转、缩放、平移与节点命中共享同一套投影。支持双指缩放、滚轮、键盘以及复位按钮。搜索、脑区筛选和详情仍使用受保护的同一份数据接口。

`deploy/room3d/` 包含六个独立场景的页面和模块。站点将这些文件放在 /room3d/house-sync/，首页与 /room3d/home.html 可以复用同一个 HTML。原像素首页可通过 /pixel-room.html 打开。页面使用站点的 Three.js r160（MIT）、GLTFLoader 及 @pixiv/three-vrm 3.0.0（MIT），由 /room3d/vendor/ 提供。

六个场景按需初始化，跟随模式从公开房间状态映射当前活动和位置，手动参观时只展示当前空间的家具。角色资产为 pixiv 的 Vita（β Ver AvatarSample_3，CC0）。部署时将上游模型文件 Vita.vrm 保存到 /room3d/assets/vita.vrm。首屏等待当前模型，失败时提供重试。代码仓库无需附带模型文件。

- [pixiv 发布条款](https://vroid.pixiv.help/hc/en-us/articles/360014900113)
- [Vita.vrm 源文件](https://github.com/madjin/vrm-samples/blob/master/vroid/beta/Vita.vrm)

发布时先验收 /room3d/house-sync/home.html 的 WebGL、房门、共享导航、实时状态与模型加载，再切换首页。

聊天、房间和控制台共享服务器发布的活动与外观快照。脑图使用同份快照中的情绪和需要，同时列出已确认的成长。房间按动作编号播放姿势；浏览者通过房门切换视角。
