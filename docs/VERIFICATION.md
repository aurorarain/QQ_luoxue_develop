# 验证说明（匿名与合成案例）

本文件替代实例运维与互动摘录。以下全部是合成场景与通用验收要求，不是任何人的聊天记录、居住信息或线上结果。

## 离线回归

安装 requirements-dev.txt 中的依赖后运行：

```sh
python -m unittest discover -s tests
```

- 身份：主人与普通成员分别使用虚构账号，验证普通成员不能修改持久记忆、成长或配置。
- 匿名点名：测试甲、乙示例和测试丙用于验证全名、简称、多人点名及未知成员回退，均非真实昵称。
- 搜索：合成消息“示例商城的价格贵不贵？我现在住在上海市”用于验证第一人称居住信息不会进入公开查询。
- 绘图：合成的画猫、请求取消及评价用语用于验证触发、取消、异常反馈与记录边界。
- 语音：合成请求用于验证正向意图、否定意图、发送方式与失败回退。
- 媒体：测试图片、占位链接和临时状态验证作用域、合并、去重和配额。
- 记忆：合成证据验证候选、冷却、确认、撤销及非主人拒绝分支。

## 需要私有环境验收的项目

真实平台鉴权、音色、消息展示、发布可见性与服务可用性均需独立验证。公开仓库不保存真实回复、群成员、实例健康信息、实际网络配置、路径、日志或备份记录。

测试通过只证明对应离线场景；不表示任何真实账号已登录、消息已发送或动态已发布。
