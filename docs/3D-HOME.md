# 3D 家居细节

`deploy/room3d` 中的入口和模块配套发布。入口加载 `/room3d/house-motion/loft.js`，该目录应包含所有同级 JS 模块。模型和 Three.js / VRM 依赖仍由入口中的公共资源路径提供。先完整发布模块，再切换入口；回退时恢复旧入口及其对应资源，避免混用缓存中的不同版本。

六个房间共用木纹、织物、金属材质和受控阴影。装饰、植物、外设和桌面物品在 `details.js` 分房间配置。现有 VRM 形象及其来源署名保留，表情跟随公开房间状态中的情绪描述，手指和坐姿由有限姿势控制，不代表新增了运动捕捉或语音口型同步。

`bedding.js` 生成带织物纹理、绗缝、包边、翻折和下垂边缘的被面，以及枕头与缝边。睡觉和卧床休息启用随身体隆起的被面，离床后恢复平铺。轻微起伏用于表现呼吸，减少动态效果模式会停止它。这是预设曲面，不是实时布料物理模拟。

卧床位置、朝向、床品隆起需要一起校准；更换模型身高后应重新核对枕头、领口和脚部。游戏、浏览和书写使用椅子坐姿；台面活动朝向工作区域。

验收应分别检查六个房间、卧床与离床切换、坐姿、角色近景、门、灯光、缩放、拖动、手机布局和减少动态效果模式。用合成状态预览各种姿势，与真实运行状态下的浏览器检查分开记录。

动作由 motion.js 管理离开、行走、转身、进入、使用与收尾阶段，重复状态轮询不会重启动作。同一座位的活动切换先放回道具，不重新起坐。导航在 navigation.js 中避开主要家具；门的完成回调驱动跨房间衔接。首次加载与减少动态效果模式直接呈现当前状态。

当前动作覆盖站立、行走、坐下起身、卧床起身、读书翻页、写画、游戏、浏览、手机、做饭、清洗、进食、浇水、抚摸、开箱、归书、整理衣服、伸展、看窗外、听歌和看剧。清洗、开箱、归书、整理衣服与伸展完成一次后回到休息姿势，其他持续活动以操作和休息周期交替。道具、被面与手部接触为骨骼程序动画，仍需与新模型或更改后的家具重新校准，不等同于动作捕捉或完整物理仿真。
