# 部署说明（公开通用版）

本文仅说明可复用的配置过程，不记录任何实际实例、私有路径、主机地址、端口映射、账号、证书位置、备份批次或运行日志。

## 准备

- 单独安装兼容版本的 AstrBot 与 NapCat，完成自己的账号授权。
- 按 config 中的空白示例创建私有配置，填写主人、群和机器人标识。不得将实际配置提交到 Git。
- 第三方扩展按 deploy/reviewed-plugins.json 固定来源与版本，保留原许可证。
- 服务器目录、网络、证书、鉴权和备份方案在私有运维记录中维护。

## 可选服务

- 语音使用 FISH_AUDIO_API_KEY、FISH_AUDIO_MODEL、FISH_AUDIO_REFERENCE_ID 和可选 FISH_AUDIO_PROXY。参考音色 ID 必须由维护者提供，源码不含默认私人音色。
- 生图按私有 image_api 配置启用；未配置时保持不可用，不复用聊天服务凭据。
- 账号登录、社交平台授权和媒体授权分别管理，不以单元测试替代真实授权。

## 维护脚本

- apply_runtime_patches.py 的 LUOXUE_DATA_ROOT 必须显式设置为维护者自己的数据根目录。
- configure_reviewed_plugins.py 接收 --data-root 参数。
- refresh_proxy_candidates.py 接收 --config 参数和私有候选输入；输入文件不可提交。
- 脚本执行前在私有环境备份并检查兼容性。仓库隐私修订不包含生产部署授权。

## 验收

先完成离线回归，再在自己的环境检查鉴权、消息隔离、工具权限和失败处理。涉及发送、发布、收藏或账号状态修改的验证需单独授权；结果保存在私有记录中。

公开示例中的服务名、回环地址和容器标准目录属于通用样例，不对应维护者的实际主机。公开部署及验证文档不列出任何 IP 字面值。
