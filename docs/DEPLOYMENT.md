# 部署、权限与能力边界

## 环境

当前适配 AstrBot 4.29.3 / NapCat OneBot v11；运行目录是 `/AstrBot/data`，主机上绑定 `/opt/luoxue/astrbot/data`。4GB CPU服务器可以运行这些API与轻量插件，不建议同时运行ComfyUI、本地TTS/视频生成或多个常驻浏览器。

`plugins/luoxue_social` 安装到data/plugins。按示例创建私有settings JSON，再执行 `scripts/apply_runtime_patches.py`。脚本会备份并收紧危险执行权限、修改已存在的语音/记忆集成、关闭空间插件原来的自动任务。它假定基础框架和集成插件已经部署，不是全新机器一键安装器。

空间底层另行安装 `https://github.com/Zhalslar/astrbot_plugin_qzone`；当前集成版本v3.1.3。其`requirements.txt`须安装，且不要更新覆盖本地禁用原监听器的修改。

## 权限与成长

- 主人的真实QQ号来自私有配置，不信任昵称或聊天自称。
- 群内所有成员都能按唤醒条件互动，只有指定群被处理。其他私聊仍由白名单拦截。
- 群模型是独立无工具请求，不读取私人角色卡和私聊记忆。临时英语等风格请求允许，但不写持久人格。
- 记忆插件的读写工具与注入额外校验：必须是主人私聊。主人可在那里调整人设、成长；不允许群成员或外部内容操作它们。
- 即使主人要求执行Shell、改环境、管理目录也拒绝；这类配置由维护者完成。图库写入仅限固定插件目录，不暴露任意文件路径工具。
- `on_llm_request` 使用工具允许名单，复制工具集合后过滤，避免污染全局工具。
- QQ侧核心配置管理命令整体禁用，防止通过管理指令安装插件或修改环境；本插件的状态、语音及记忆工具不受影响。环境配置使用服务器/WebUI维护，不通过QQ让模型执行。

## 群感知

此前只保存唤醒聊天，新版增加被动文字观察。观察本身不唤醒回复，仍仅在@、名字前缀、戳一戳、成员加入时输出。观察后群记录可被主人私聊检索。安装前历史、未解析的图片和未播放的视频不得声称看过。

成员名单由NapCat `get_group_member_list`读取并缓存10分钟。新成员加入通知会强制刷新；欢迎最多发一次。模型输出的 `[at:QQ]` 只有名单内真实QQ会变成At组件，最多一个，不允许@全体。

## 语音

默认继续现有Fish音色和模型，不切换收费档。S2方括号情绪提示由`voice_control.py`添加，剔除表情标签和舞台动作。HTTP成功只能证明合成成功，情绪是否自然还需实际试听。

代理订阅节点可能过期。维护脚本`refresh_proxy_candidates.py`可从私有导出的proxies JSON中选出TCP可达候选，生成Fish/海外素材走代理、其余直连的规则；输入包含订阅凭据，权限必须600，不能提交Git。生成后先用Mihomo配置校验，再重启代理，再实测Fish请求。TCP可达和gstatic健康测试都不能代替实际TTS验证。

可选API：MiniMax Speech系列有emotion与语气词控制；阿里云CosyVoice部分模型/音色支持情绪。都需独立凭据和音色试听，不保证能复用Fish参考ID。

官方参考：
- https://docs.fish.audio/developer-guide/core-features/emotions
- https://platform.minimaxi.com/docs/api-reference/speech-t2a-http
- https://help.aliyun.com/zh/model-studio/action-emotion-control-practice

## 图像与表情

不依赖ComfyUI。填写私有配置image_api的base_url、api_key、model后才实际启用，默认每天最多3次API尝试。现有DeepSeek聊天key不能用于OpenAI Images API。未配置时明确提示。

表情库：`data/plugin_data/luoxue_social/表情包/{分类}/`，包括`index.json`和`README.md`。开始可使用12张Twemoji种子素材（CC-BY-4.0，逐项记录来源）。这只是起步素材，后续可手动加入真正的图片/GIF表情。

仅偶尔收集主人发出的平台标记表情，或带明确收藏请求的图；普通照片不静默收录。入库经过视觉审核、哈希去重、每图3MB/400万像素、每天12张限制。私人收录仅用于私聊。视觉判断不绝对可靠，重要照片不要作为收藏表情发送。

发送使用分类匹配与最近5张排除；没有候选就不发，不为凑数重复相同图片。API生图与素材下载有公共HTTPS、字节上限和私网地址拦截。

## 自主说说和评论

发说说仍是“每3小时最多判断一次、每天最多一次发布尝试”，不是每次聊天都发。新提示强调短句、洛雪口吻、具体感受，禁止总结宣言和模板陪伴话术；参考主人沉默时长、私聊/相关群聊与实际读取的公开内容，私聊细节不得公开。

可搜索Wikimedia Commons配图，只接受其标记CC0/Public domain的静态图片，保留来源；没有合适结果就纯文字。没有逐张证明搜索结果语义完全匹配，不应强制给每条动态配图。

每30分钟低频检查自己最近3条和好友动态流最多3条，初次启用只建立旧评论基线。新评论用帖子ID、作者、评论ID、父ID、时间与内容哈希去重；支持楼中楼的主评论ID定位。只回复自己动态的新评论，及已参与的其他动态线程；偶尔主动评论好友或给自己补充后续。不保证每条垃圾/敏感评论都会回复，也不保证所有新回复措辞永远无语义相似。

每天最多8次互动尝试，失败不无限重试。点赞接口返回成功不代表QQ空间可见点赞；上游也记录了可见性问题，要分开报告API接受与客户端验证。

## 自主活动与视频边界

有空且主人至少30分钟未聊天时，每6小时最多获取一次公开热门内容，先尝试B站公开标题/简介，受限时回退V2EX公开主题。选出一个真实可追溯的新鲜话题保存到discoveries，供之后私聊/说说判断使用。此步骤不主动往群里发消息。

这不是完整观看、截图刷视频或登录后的个性化推荐流。B站/抖音链接解析社区插件可作为后续扩展，但不能把“拿到链接信息”冒充“自己刷完视频”。实际读取内容可生成带来源的资讯卡片（明确标注不是网页截图），在主人专属主动消息中低频分享。还可用固定FFmpeg参数在CPU上渲染12秒竖版字幕卡片MP4草稿，每天最多一份，不是AI动画。模型不能控制命令或输出路径。

抖音发布需要开发者应用、video.create权限、OAuth账号授权等，当前未提供凭据，保持禁用；不借用其他用户浏览器Cookie、不假装发布成功。生成短视频也需要独立媒体制作流程或视频API，本仓库没有配置其付费key。

官方限制：https://open.douyin.com/platform/resource/docs/openapi/video-management/douyin/create/create-video

## 检查

`/status`、`/状态`、`/社交状态`查看轻量状态，不让它们进入普通模型生成。`health.json`检查空间只读登录与模型探测；真实成员名单可在配置探测任务里调用。

运行 `python -m unittest discover -s tests -v`。测试覆盖群唤醒、戳目标、工具允许名单、SQL记忆隔离、被动观察不唤醒、表情隐私范围与轮换、私网URL拒绝和语音标记。

部署后还应在真实QQ验收成员加入、@、发送表情、情绪试听、评论楼中楼；没有真实事件时只能报告逻辑测试通过，不得称客户端端到端完成。
