# QQ 洛雪

基于 AstrBot + NapCat 的 AI 伙伴扩展，提供私聊与群聊隔离、受限记忆工具、语音、图像和公开资讯功能。

## 配置与安装

1. 安装并连通 AstrBot 与 NapCat。运行配置、账号授权和部署位置由维护者在私有环境管理。
2. 安装本仓库 plugins 下的扩展，按 config 中的示例填写自己的配置；示例不得包含实际账号或凭据。
3. 语音凭据和参考音色通过环境变量提供。生图使用独立服务商配置。
4. 第三方扩展版本与许可证见 deploy/reviewed-plugins.json；原始来源和适配脚本保留。
5. 按 docs/DEPLOYMENT.md 配置，按 docs/VERIFICATION.md 验证。

## 数据边界

只有配置验证的主人可维护持久记忆和成长。群聊不读取私聊上下文、私人图片或私人记忆；昵称和聊天自称不构成授权。

公开仓库只保存代码、空白配置和合成测试。运行凭据、账号、聊天、画像、登录缓存、日志、数据库、备份和素材不随源码发布。角色“洛雪”是项目虚构角色，不代表真实用户。

公开文档不记录具体实例的地址、部署路径、拓扑、备份时间、在线状态或真实互动。部署和第三方效果需在私有环境独立验收；单元测试不代表线上发送成功。

自主活动是定时器、状态和模型判断产生的行为，不是自我意识或真实线下生活。
